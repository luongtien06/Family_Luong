Cấu hình Quản trị viên (Admin Sync)

Bảo mật cao nhất:
  • GitHub PAT được bảo vệ an toàn trong Cloudflare Secrets, không bao giờ lộ ra trình duyệt.
  • Đồng bộ nguyên khối (Atomic Git Data API) cả ảnh và data.json trong 1 commit duy nhất.
Chế độ dự phòng:
  • Dùng khi chưa triển khai Cloudflare Worker. Token chỉ lưu trong phiên (sessionStorage).
  • Nên dùng Fine-grained Token với quyền: Contents (Read & write), Metadata (Read).
